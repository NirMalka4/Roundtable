# Security Policy

## Supported versions

Security fixes are supported for the latest release and the current `main`
branch only.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/NirMalka4/Roundtable/security/advisories/new).
Do not disclose a suspected vulnerability in a public issue or discussion.

Roundtable runs local tools and processes repository and review content.
Relevant reports include:

- unintended command or tool execution;
- repository or worktree boundary violations and path traversal;
- credential exposure or secret retention in artifacts;
- unsafe Azure DevOps publication or external-state mutation; and
- injection or unsafe rendering of untrusted report content.

Include reproduction steps, affected versions, impact, and any suggested
mitigation when available.
